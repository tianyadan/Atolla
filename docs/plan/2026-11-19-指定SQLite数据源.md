# 指定 SQLite 数据源（Web / Electron）

## 1. 背景

Web 与 Electron 默认使用不同 SQLite 文件，数据不互通。设置页已能切换 SQLite/MySQL，但无法手动指定 `.db` 路径；Electron 启动还会强制写入默认 `AVATAR_DB_DSN`。

已确认方案：**改 DSN 指向目标文件 + 可选把当前库拷到空/新文件**（不覆盖已有数据库）。

## 2. 开发目标

1. 设置 → 数据库：SQLite 可编辑路径、浏览文件、恢复默认、应用并重启。
2. `POST /api/admin/db/sqlite-path` 持久化到 runtime/repo `.env`。
3. `migrate=true` 仅当目标空/新且当前有数据时拷贝。
4. 修正 status 返回**实际** sqlite 路径；Electron 尊重已保存 DSN。

## 3. 实现范围

### 本次实现

- 后端：路径校验、写 env、可选 sqlite→sqlite 迁移、重启。
- 前端 DbSettings：路径编辑 + 确认弹窗。
- Electron：选文件 IPC；启动时不覆盖已有 DSN。

### 本次暂不实现

- 两库合并、双写同步、MySQL 自定义 DSN UI。

## 4. 技术设计

见 `docs/superpowers/specs/2026-11-19-sqlite-path-select-design.md`。

核心流程：

```text
用户选路径 → 校验绝对路径/.db
  → migrate? 目标空且当前有数据 → CopyAll
  → UpsertEnv AVATAR_DB_DSN
  → restart.sh / desktop 重启后端
```

## 5. 变更影响

- `.env` 可指向任意本机 `.db`；Web/Electron 可共用同一文件（勿双开写）。
- Electron 打包态依赖 `AVATAR_RUNTIME_ROOT` 下 `.env` 保留用户选择。
