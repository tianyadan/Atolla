# 实例验证码登录（SMTP + Face ID）

## 背景
手机/Web 能进中继，但缺少 Mac 6 位实例密码时无法解锁。

## 目标
解锁弹窗增加「验证码登录」：SMTP 发一次性 6 位码到用户配置的接收邮箱；App 发送前 Face ID；码最长 7 天、用过即废；unlock 会话已有 7 天不变。

## 启用条件
- Mac 远程中继页：发送邮箱 SMTP 配置且校验通过
- App/Web：已填写接收邮箱
- 否则按钮灰色

## 链路
1. Mac 配置 SMTP → test → heartbeat 上报 `unlock_otp_smtp_ok`
2. 站点保存 `receive_email`
3. `POST .../unlock-otp/send`（站点登录即可）→ 中继生成 OTP 哈希入库 → 命令 `instance.send_unlock_otp` 让 Mac 发信
4. `POST .../unlock` 校验固定密码或未使用 OTP → 签发 7d unlock_token

## 范围
Mac remotebridge + 中继 server + remote-relay web（弹窗/设置）；不解决腾讯云注册过期。
