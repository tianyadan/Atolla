# 灵动岛可调布局设计

## 目标

为 macOS 灵动岛加入低干扰的悬停式布局编辑：用户可调整位置、宽度、高度，并可选择锁定或解锁宽高比。默认行为与现有刘海对齐布局保持一致。

## 交互规则

- 指针悬停在灵动岛时显示细边框、四边与四角缩放手柄，以及用于移动的编辑握柄。
- 拖动握柄可移动灵动岛；拖动边或角可调整尺寸。
- 宽高比默认锁定，按用户开始拖动时的当前比例缩放；关闭后，水平与垂直尺寸独立变化。
- 双击编辑握柄可恢复当前屏幕的默认刘海对齐位置与大小。
- 普通内容点击继续保留现有交互，不会因为布局编辑而误触发移动。

## 数据与边界

- 每块显示器保存独立的布局偏好：位置、宽高缩放比例与宽高比锁定状态。
- 默认值为现有原生刘海尺寸与顶部居中位置。
- 约束最小和最大尺寸，并将最终位置限制在可见屏幕区域内，防止窗口被拖出屏幕而无法找回。
- 仅在拖动结束时写入 `UserDefaults`，避免高频持久化；切换显示器时自动读取对应偏好。

## 实现边界

- 新增独立布局状态模型，负责按显示器读取、校验、重置及持久化布局数据。
- `IslandPanelController` 使用布局状态计算面板最终位置和尺寸，同时继续保留现有状态动画尺寸。
- SwiftUI 视图层仅负责悬停编辑控件和拖拽事件，将语义化操作交由控制器处理。
- 不修改任务状态、事件队列和主窗口；不新增独立设置页，本次直接在灵动岛完成编辑。

## 取舍

不采用系统原生窗口缩放：非激活浮窗的原生缩放需要标题栏和边缘策略，且会破坏灵动岛的无边框体验。也不只提供设置页，因为无法满足即时拖拽调整的使用方式。
