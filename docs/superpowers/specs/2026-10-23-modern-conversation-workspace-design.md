# Atolla 现代对话工作台设计

## 意图

把后台从“菜单 → 工作组 → 数字人 → 对话”的管理型路径，改成进入即对话的工作台；保留现有经典风格，用户可以随时切回。

## 目标

- 现代风格以最近对话为左侧导航，主区域只突出当前对话和输入框。
- 新建对话使用搜索优先的单层数字人选择器，不再要求先进入工作组。
- 低频模块统一收进 `更多` SVG 菜单。
- 复用现有消息时间线、SSE、审批卡、附件、`@`、群聊和运行状态能力。
- 同一数字人支持多个会话线程，经典风格继续使用该数字人当前激活的会话。

## 非目标

- 不删除或重写经典风格。
- 不迁移 React、Vite 或现有 CSS 技术栈，不新增 UI 依赖。
- 不改变数字人执行、权限审批和群聊业务语义。
- 本轮不重新设计独立的项目协作、审计、设置等功能页，只改变其入口。

## 约束

- 现代/经典偏好保存在浏览器本地，默认继续使用经典风格，避免现有用户突然换界面。
- 新会话只能在数字人空闲时创建或激活，避免把运行中的流切到另一个线程。
- 现代风格在桌面端为 272px 最近对话栏；窄屏降为可抽出的侧栏。
- 状态优先级保持：报错 > 待审批 > 运行中 > 已完成。

## 采用方案

采用“同一 React 应用双壳层 + 共享业务组件”：经典壳层保持现状；现代壳层新增 `ModernWorkspace`，左侧读取数字人会话摘要，右侧以 `ManagedAgentsPanel` 的聚焦模式复用现有对话能力。数据库沿用 `conversations.agent_id`，给会话补充标题、置顶和归档字段，`managed_agents.conversation_id` 继续作为当前激活会话指针。

没有采用纯 CSS 换皮，因为它无法消除嵌套导航；也没有另建前端项目，因为会复制 SSE、审批和附件等高风险业务逻辑。

## 交互

### 现代首页

- 左侧顶部：新建对话、搜索。
- 左侧列表：置顶、今天、昨天、最近 7 天、更早；每项显示标题、数字人、时间和最高优先级状态。
- 主区顶部：当前数字人、部门、引擎、状态、运行时长、审批入口、更多操作。
- 主区底部：现有输入框、附件、`@` 和发送行为。

### 新建对话

- 打开居中选择器，单层展示最近使用和全部数字人。
- 支持姓名、部门、引擎搜索以及键盘上下选择/回车确认。
- 创建成功后立即激活该会话并进入空白时间线。

### 更多菜单

收纳数字人管理、群聊、记忆、项目协作、备忘录、审计、数据分析、远程中继、网络白名单、设置、手册和版本。进入低频模块时提供“返回对话”入口。

### 风格切换

- 设置和现代更多菜单均提供“现代/经典”切换。
- 切换只改变壳层，不改变选中的数字人、运行任务或权限状态。

## 数据与接口

- `conversations` 新增 `title`、`pinned`、`archived`。
- `GET /api/admin/agent-conversations?limit=100&archived=0`：最近对话摘要。
- `POST /api/admin/agents/:id/conversations`：创建并激活新会话。
- `POST /api/admin/agents/:id/conversations/:conversationId/activate`：激活历史会话。
- `PATCH /api/admin/agent-conversations/:id`：更新标题、置顶或归档状态。

## 视觉规范

- 背景 `#0D0E10`，侧栏 `#111215`，浮层 `#17181C`，边框 `#282A30`。
- 主文字 `#F0F1F3`，次文字 `#9297A1`，单一主强调色 `#8EA7FF`。
- 字体使用系统 SF Pro/Segoe UI；正文最大宽度 880px。
- Hover 160ms，侧栏 220ms，按压 `scale(0.985)`，动画只使用 opacity/transform。

## 验收

- 默认经典风格完全可用；切换现代风格后刷新仍保持。
- 现代首页不出现旧全局侧栏和工作组嵌套列表。
- 最近会话可搜索、切换、置顶、归档；新建会话不会清空旧会话。
- 同一数字人在运行时不能切换或新建线程，并给出明确提示。
- 现有聊天、审批、停止、附件、群聊和深链功能不回归。
